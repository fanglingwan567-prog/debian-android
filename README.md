# Debian

把 Debian 终端装进口袋：在已 root 的 ARM64 Android 设备上下载、安装并原生运行 Debian，无需虚拟机或 CPU 仿真。

## 产品功能

- **本地 Debian 环境**：从 Debian 官方容器镜像选择稳定版或测试版，下载后安装到应用私有目录。
- **自定义 root 入口**：在授权页直接填写 su 路径，留空使用系统 su，设置可保存。
- **完整终端交互**：支持中文输入、终端历史滚动、双指缩放字号、长按选择和复制文字。
- **快捷操作**：提供 ESC、TAB、CTRL、ALT、方向键、HOME、END 和翻页键；方向键支持长按连发。
- **会话保留**：切换应用或返回桌面时保留当前会话，确认退出后结束会话，系统文件保留。
- **本地优先**：无遥测、无远程网页。首次下载系统需要联网，安装完成后启动终端无需联网；终端内的联网操作仍需要网络。

## 设备要求

- Android 9 或更新版本。
- ARM64 设备，已获取 root 权限，并有可用的 su。
- Android Toybox 和较新的系统 WebView。
- 足够的存储空间，以及首次下载系统所需的网络连接。

部分设备可能因 SELinux、厂商内核或 root 管理器限制而无法启动，应用不会关闭 SELinux。

## 开始使用

1. **授予权限**：按需填写 su 路径，点击授权，并在 root 管理器中允许访问。
2. **下载系统**：选择 Debian 分支和版本，下载对应的 ARM64 镜像。
3. **安装系统**：确认安装，完成后进入 Bash 终端。

已安装系统后，再次打开应用可直接进入终端。账号和密码由 Debian 自身管理，应用不预设账号密码。

## 终端操作

- 轻点终端唤起键盘，按系统返回键收起键盘。
- 单指上下拖动查看历史，双指捏合调整字号。
- 长按文字进入选择，拖动选区或手柄调整范围，轻点高亮文字复制。
- 点击 CTRL 或 ALT 后再输入目标按键，再次点击可取消。
- 使用 `exit` 退出最外层 Shell，或确认退出应用，结束当前会话。

## 数据与安全

Debian 安装在应用私有目录，正常结束会话不会删除系统文件。**卸载应用或清除应用数据会同时删除 Debian 和其中的文件，请提前备份重要数据。**

此环境使用手机的 root 权限，**不是安全沙箱**。请勿执行来源不明的命令、脚本或程序。

本产品不提供非 root 模式，也不承诺兼容 systemd、Docker 或退出后持续运行的后台任务。
